# Synthetic Engram 0.2 legacy reference

This directory preserves the package-oriented Synthetic Engram 0.2 guidance,
planning material, interoperability report, requirement catalog, and security
review. It is reference material only; current development is the
[Engram Mesh 0.3 pilot](../../../SPEC.md).

The 0.2 normative specification is preserved here as [`SPEC.md`](SPEC.md). The `v0.2` schemas,
examples, fixtures, and adapters retain their original meaning and are not a
Engram Mesh representation.
