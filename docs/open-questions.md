# Open questions after v0.1

The following are intentionally deferred rather than implied by v0.1:

- canonical archive media type and deterministic archive serialization;
- fragments, lenses, and deterministic query grammar;
- namespace membership and cross-namespace policy;
- revision snapshots, deltas, deletion, and conflict semantics;
- synchronization and change streams;
- portable authority descriptors and signatures;
- generic graph layout and richer graph semantics;
- data snapshots, units, and authoritative-source descriptors;
- AI-oriented context views and bounded retrieval;
- cross-standard adapter and provenance metadata;
- migration rules between major versions; and
- certification and compatibility branding.

Proposals should use the process in `GOVERNANCE.md` and include data examples,
compatibility analysis, security considerations, and conformance tests.
